### Hey, I'm Massimo. 👋

I'm a Laravel developer, founder and teacher in **Limburg, Belgium**. I run **Assurio BV**, a one-person software company, and turn messy business problems into useful, human-friendly software.

> **Less busywork. More building.**<br>Good software should give people time back—not another thing to wrestle with.

## ⚡ What keeps me busy

**🏗️ Building for the real world**<br>I create custom Laravel applications and build [Assurio](https://assurio.be), a multi-tenant SaaS for Belgian insurance brokers. From the first conversation to the final deployment, the people using the software stay at the center.

**🤖 Making AI earn its place**<br>I put AI into actual workflows, where it can take repetitive work off someone's plate. Less demo magic, more practical results.

**🎓 Passing it on**<br>At [SyntraPXL](https://www.syntrapxl.be) in Genk, I teach full stack AI automation, Laravel and React, as well as courses on vibe coding and applied LLM agents.
